# Targets

Location-scoped naming and structural patterns for filing destinations.

---

## Format

Each target specifies the path it applies to and the pattern to follow.

Targets are a user-only artifact. Only the user can create, modify, or remove targets — directly, via AI assistance, or by accepting agent suggestions.

Naming targets specify the exact format to follow — do not augment, prefix, or modify. Fields marked as optional may be omitted when not applicable, but no additional fields should be added.

Each target includes `created` and `updated` dates for orientation.

### Example target

```markdown
### Archive/*/Finance
- All receipts are filed flat into a `Receipts/` folder. No sub-grouping. (created: 2026-04-09, updated: 2026-04-09)
```
